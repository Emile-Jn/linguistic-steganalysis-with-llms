# Data

This directory contains the datasets used for binary classification.  
Each dataset contains one text sample per line.

## Baseline
The subdirectory `baseline` contains the original data provided by the repo [Linguistic-Steganalysis-with-LLMs](https://github.com/ba0z1/Linguistic-Steganalysis-with-LLMs).  
Each subdirectory inside `baseline` contains a cover-stego pair. The `cover.txt` file is the IMDB reviews dataset
that they use for all experiments. 
The `stego.txt` file is a dataset generated by GPT-2 trained on `cover.txt`, using the 
steganographic method that corresponds to the name of the subdirectory.

## Qwen-generated
The subdirectory `qwen_generated` contains a pair of datasets used to assess if the 
steganalysis model distinguishes between natural and LLM-generated texts.
The `cover.txt` file is the same IMDB reviews dataset as in the `baseline` subdirectory.
The `gen_cover.txt` file is a dataset generated by Qwen3-8B fine-tuned on `cover.txt`.

## Qwen-stego
The subdirectory `qwen_stego` contains a dataset generated by Qwen3-8B fine-tuned on 
`cover.txt` using Arithmetic Coding as the steganographic method.
